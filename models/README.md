# Modele

Repozytorium zawiera dwa zapisane artefakty modeli używanych przez notebook główny:

- `spot_price_forecast_model.pkl` — model prognozy ceny SPOT,
- `heat_demand_forecast.pkl` — model prognozy zapotrzebowania na ciepło.

Model ceny SPOT został zachowany w repozytorium zgodnie z przyjętą strukturą projektu. Dane treningowe nie są publikowane.

Pliki `.pkl` są artefaktami środowiska Python i mogą być wrażliwe na różnice wersji bibliotek. W przypadku problemów z kompatybilnością zalecane jest ponowne wytrenowanie modelu przy użyciu odpowiedniego notebooka i własnych danych wejściowych.
